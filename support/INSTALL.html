安装 RelayDock

RelayDock 0.1.0 · Cursor 网络链路探针 MVP

推荐安装方式
  1. 右键点击 Install RelayDock.command。
  2. 选择“打开”，在 macOS 提示中再次确认。
  3. Terminal 打开后输入 y，并按提示输入 Mac 登录密码。
  4. 脚本会校验 App、安装到 /Applications、执行本地签名并启动。

为什么需要右键打开？

当前个人测试包没有 Apple Developer ID 与公证票据。安装脚本会在本机执行 ad-hoc 签名，用户无需手动输入 codesign。正式公开分发仍建议使用 Developer ID 签名与 Apple notarization。

开始探测

  1. 打开 RelayDock，点击“启动探测代理”。
  2. 点击“重启 Cursor 并探测”。
  3. 在 Cursor 中使用 Anthropic BYOK 发送一条测试消息。
  4. 回到 RelayDock 查看是否出现 api.anthropic.com。

范围说明：0.1.0 只观察 CONNECT 目标域名，不解密 HTTPS，也不会把 Anthropic 请求重定向到 Sub2API。是否能安全加入 TLS Bridge，取决于本次探测结果。

卸载

右键打开 Uninstall RelayDock.command，它会删除 App、RelayDock 偏好设置以及保存在 Keychain 中的网关 API Key。此版本不会安装根证书或修改系统代理。
