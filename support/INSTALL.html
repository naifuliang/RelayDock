安装 RelayDock

RelayDock 0.1.0 · Cursor 网络链路探针 MVP

最简单：复制一条命令

打开 macOS 自带的“终端”（Terminal），粘贴下面整行命令并按回车：

/usr/bin/curl -fsSL https://raw.githubusercontent.com/naifuliang/RelayDock/main/install.sh | /bin/zsh

输入 y 确认，再按提示输入 Mac 登录密码。脚本会从 GitHub 下载最新版本，使用发布的 SHA-256 与现有 App 签名检查文件完整性，然后安装并启动 RelayDock。这些检查不等同于 Apple 公证。

安全范围：安装器不会全局关闭 Gatekeeper、安装根证书或修改系统代理。对于当前未公证测试版，它只会移除 RelayDock 安装副本的 quarantine 属性并执行本地 ad-hoc 签名。脚本源码可在 RelayDock 的公开 GitHub 仓库中审阅。

离线备用：从当前磁盘映像安装
  1. 保持 RelayDock 磁盘映像窗口打开，然后打开 macOS 自带的“终端”（Terminal）。
  2. 在终端中输入 /bin/zsh ，注意末尾需要保留一个空格，先不要按回车。
  3. 把磁盘映像窗口里的 Install RelayDock.command 直接拖到终端窗口。终端会自动填入正确路径。
  4. 按回车运行。出现 Continue? [y/N] 后输入 y，并按提示输入 Mac 登录密码。
  5. 脚本会校验 App、安装到 /Applications、执行本地签名并启动。

离线安装注意：不要直接双击脚本，也不要只把脚本拖到终端后运行。命令最前面必须有 /bin/zsh。完整命令看起来类似：
/bin/zsh "/Volumes/RelayDock 0.1.0/Install RelayDock.command"

为什么不能直接双击？

当前个人测试包还没有 Apple Developer ID 与公证票据。直接双击会触发“无法验证是否包含恶意软件”的 Gatekeeper 提示。安装脚本会在本机执行 ad-hoc 签名，用户无需手动运行 codesign。上面的拖拽方式也不依赖固定卷名，因此即使系统把磁盘映像命名为 RelayDock 0.1.0 2 也能正确运行。

也可以在弹窗中点击“完成”，然后前往“系统设置 → 隐私与安全性 → 安全性”选择“仍要打开”。不要全局关闭 Gatekeeper，也不要使用 spctl --master-disable。

开始探测

  1. 打开 RelayDock，点击“启动探测代理”。
  2. 点击“重启 Cursor 并探测”。
  3. 在 Cursor 中使用 Anthropic BYOK 发送一条测试消息。
  4. 回到 RelayDock 查看是否出现 api.anthropic.com。

范围说明：0.1.0 只观察 CONNECT 目标域名，不解密 HTTPS，也不会把 Anthropic 请求重定向到 Sub2API。是否能安全加入 TLS Bridge，取决于本次探测结果。

卸载

右键打开 Uninstall RelayDock.command，它会删除 App、RelayDock 偏好设置以及保存在 Keychain 中的网关 API Key。此版本不会安装根证书或修改系统代理。
