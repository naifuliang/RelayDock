安装 RelayDock

RelayDock 0.3.1 · 可验证升级、多端点与模型发现

最简单：复制一条命令

打开 macOS 自带的“终端”（Terminal），粘贴下面整行命令并按回车：

/usr/bin/curl -fsSL https://raw.githubusercontent.com/naifuliang/RelayDock/main/install.sh | /bin/zsh

输入 y 确认，再按提示输入 Mac 登录密码。脚本会从 GitHub 下载最新版本，使用发布的 SHA-256 与现有 App 签名检查文件完整性，然后安装并启动 RelayDock。这些检查不等同于 Apple 公证。

安全范围：安装器不会全局关闭 Gatekeeper、安装受信任根证书或修改系统代理。对于当前未公证测试版，它只会移除 RelayDock 安装副本的 quarantine 属性，并在 ~/Library/Keychains/RelayDockLocalSigning.keychain-db 创建一个稳定、仅供 RelayDock 使用的本地签名身份。该 Keychain 只加入用户 Keychain 搜索列表，便于 macOS 找到签名证书，不会添加证书信任；卸载时会删除 Keychain 及搜索列表项。

从旧版升级：旧版使用每次变化的 ad-hoc 签名。RelayDock 会禁止 Keychain 弹出交互授权框；若旧 Endpoint Key 因签名变化无法读取，界面会显示为空，需要重新填写一次。之后由稳定本地签名安装的版本会持续复用同一身份，不再弹密码框。

离线备用：从当前磁盘映像安装
  1. 保持 RelayDock 磁盘映像窗口打开，然后打开 macOS 自带的“终端”（Terminal）。
  2. 在终端中输入 /bin/zsh ，注意末尾需要保留一个空格，先不要按回车。
  3. 把磁盘映像窗口里的 Install RelayDock.command 直接拖到终端窗口。终端会自动填入正确路径。
  4. 按回车运行。出现 Continue? [y/N] 后输入 y，并按提示输入 Mac 登录密码。
  5. 脚本会校验 App、安装到 /Applications、执行本地签名并启动。

离线安装注意：不要直接双击脚本，也不要只把脚本拖到终端后运行。命令最前面必须有 /bin/zsh。完整命令看起来类似：
/bin/zsh "/Volumes/RelayDock 0.3.1/Install RelayDock.command"

为什么不能直接双击？

当前个人测试包还没有 Apple Developer ID 与公证票据。直接双击会触发“无法验证是否包含恶意软件”的 Gatekeeper 提示。安装脚本会完成本地签名，用户无需手动运行 codesign。上面的拖拽方式不依赖固定卷名，即使系统给磁盘映像添加数字后缀也能正确运行。

也可以在弹窗中点击“完成”，然后前往“系统设置 → 隐私与安全性 → 安全性”选择“仍要打开”。不要全局关闭 Gatekeeper，也不要使用 spctl --master-disable。

配置多个端点与 OpenCode

  1. 在同一张 Endpoints 配置卡里点击“添加 Endpoint”，添加 OpenAI Compatible、OpenAI Responses、Azure OpenAI 或 Anthropic 端点。
  2. 填写 URL 和 Key 后点击“同步模型”，RelayDock 会测试连接并自动获取模型列表。
  3. 点击“一键验证全部”，RelayDock 会向每个已启用模型发送最小请求并分别显示成功或失败；这可能产生极少量 API 用量。
  4. Azure 已停用旧版 deployment 列表接口，因此旧 deployment URL 模式需要手动添加 deployment ID 后再“一键验证”；现代 Azure v1 端点仍可同步模型。
  5. 先完全退出已经运行的 OpenCode.app，再点击“配置并启动 OpenCode”。RelayDock 使用独立的 OPENCODE_CONFIG，不会覆盖已有全局配置。
  6. 应用每天自动检查一次 GitHub Release，Updates 卡片会显示结果与时间。发现更新后，“下载并安装”会校验 digest、挂载后 App 的签名与版本，打开安装器，并在重启 RelayDock 前确认已安装版本。

Cursor 网络探测

  1. 打开 RelayDock，点击“启动探测代理”。
  2. 点击“重启 Cursor 并探测”。
  3. 在 Cursor 中使用 Anthropic BYOK 发送一条测试消息。
  4. 回到 RelayDock 查看是否出现 api.anthropic.com。

范围说明：0.3.0 已直接支持 OpenCode 多端点，并可一键普通启动 OpenCode 与 Cursor；Cursor 的端点能力仍只做 CONNECT 目标探测，不解密 HTTPS，也不会把 Anthropic 请求重定向到 Sub2API。界面会明确区分这些能力。

卸载

使用 /bin/zsh 运行 Uninstall RelayDock.command。它会删除 App、全部端点与 Keychain API Key、RelayDock 生成的 OpenCode 配置，以及私有本地签名 Keychain。此版本不会安装根证书或修改系统代理。
