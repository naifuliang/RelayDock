Install RelayDock

RelayDock 0.1.0 · Cursor Network Probe MVP

Recommended installation
  1. Right-click Install RelayDock.command.
  2. Choose Open, then confirm the macOS prompt.
  3. When Terminal opens, enter y and provide your Mac login password when requested.
  4. The script verifies the app, installs it in /Applications, applies a local signature, and launches RelayDock.

Why is right-click Open required?

This personal test build does not yet have an Apple Developer ID or notarization ticket. The installer applies an ad-hoc signature locally, so you do not need to run codesign yourself. Public production distribution should use Developer ID signing and Apple notarization.

Run the probe

  1. Open RelayDock and click 启动探测代理 (Start Probe Proxy).
  2. Click 重启 Cursor 并探测 (Restart Cursor and Probe).
  3. Send one test message in Cursor using Anthropic BYOK.
  4. Return to RelayDock and check whether api.anthropic.com appears.

Scope: version 0.1.0 observes CONNECT destination hostnames only. It does not decrypt HTTPS or redirect Anthropic requests to Sub2API. Whether a scoped TLS bridge is viable depends on the probe result.

Uninstall

Right-click Uninstall RelayDock.command and choose Open. It removes the app, RelayDock preferences, and the gateway API key stored in Keychain. This version does not install a root certificate or change the system proxy.
